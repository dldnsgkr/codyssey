# Problem 6 - PyQt6 계산기

## 개요

PyQt6를 사용하여 만든 GUI 계산기 애플리케이션입니다. 아이폰 계산기와 유사한 레이아웃으로 기본적인 사칙연산과 부호 변환, 백분율 기능을 제공합니다.

## 파일 구조

```
problem_6/
└── calculator.py   # 계산기 UI 및 로직 구현
```

## 실행 방법

```bash
python calculator.py
```

> PyQt6가 설치되어 있어야 합니다.
> ```bash
> pip install PyQt6
> ```

## 기능

| 버튼 | 기능 |
|------|------|
| `0` ~ `9` | 숫자 입력 |
| `.` | 소수점 입력 |
| `+`, `-`, `*`, `/` | 사칙연산 |
| `=` | 수식 계산 |
| `AC` | 전체 초기화 |
| `+/-` | 부호 변환 (양수 ↔ 음수) |
| `%` | 백분율 변환 (현재 값 ÷ 100) |

## 코드 구조

### `Calculator` 클래스 (`QWidget` 상속)

계산기의 UI와 로직을 모두 담당하는 메인 클래스입니다.

#### 주요 속성

- `self.expression` : 사용자가 입력 중인 수식 문자열을 저장합니다.
- `self.display` : 수식 및 결과를 출력하는 `QLineEdit` 위젯입니다. (읽기 전용)

#### 주요 메서드

- `__init__()` : 창 제목(`Calculator`), 고정 크기(300×400)를 설정하고 `init_ui()`를 호출합니다.
- `init_ui()` : `QVBoxLayout` 위에 디스플레이와 `QGridLayout` 기반의 버튼 영역을 배치합니다. `0` 버튼은 colspan=2로 가로 두 칸을 차지합니다.
- `on_click()` : 모든 버튼의 클릭 이벤트를 처리합니다. `sender().text()`로 눌린 버튼을 식별하여 각 동작을 수행합니다.

#### 계산 처리 방식

`=` 버튼 클릭 시 Python 내장 `eval()` 함수로 `self.expression`을 계산합니다. 잘못된 수식이 입력된 경우 `except` 블록에서 디스플레이에 `Error`를 표시하고 수식을 초기화합니다.

## 사용된 라이브러리 함수

### PyQt6.QtWidgets

| 클래스 / 함수 | 설명 |
|---|---|
| `QApplication(sys.argv)` | PyQt6 애플리케이션 객체를 생성합니다. 이벤트 루프와 시스템 리소스를 관리하며, 프로그램 실행 전 반드시 하나 생성해야 합니다. |
| `QWidget` | 모든 GUI 위젯의 기본 클래스입니다. `Calculator`가 이를 상속하여 독립 창으로 동작합니다. |
| `QVBoxLayout` | 위젯을 세로(Vertical) 방향으로 순서대로 배치하는 레이아웃입니다. 디스플레이와 버튼 그리드를 위아래로 쌓는 데 사용됩니다. |
| `QGridLayout` | 위젯을 행(row)과 열(column)로 구성된 격자 형태로 배치하는 레이아웃입니다. 계산기 버튼 배치에 사용됩니다. |
| `QPushButton(text)` | 클릭 가능한 버튼 위젯입니다. `text`는 버튼에 표시할 문자열이며, `.clicked.connect(함수)`로 클릭 이벤트 핸들러를 연결합니다. |
| `QLineEdit` | 한 줄 텍스트 입력/출력 위젯입니다. 계산기 디스플레이로 사용되며, `setReadOnly(True)`로 사용자 직접 입력을 차단합니다. |

### QWidget 메서드

| 메서드 | 설명 |
|---|---|
| `setWindowTitle(str)` | 창 상단에 표시될 제목 문자열을 설정합니다. |
| `setFixedSize(w, h)` | 창의 크기를 고정합니다. 사용자가 창 크기를 조절할 수 없게 됩니다. |
| `setLayout(layout)` | 위젯에 레이아웃을 적용합니다. |
| `show()` | 위젯(창)을 화면에 표시합니다. |
| `sender()` | 시그널을 발생시킨 객체(위젯)를 반환합니다. `on_click()` 내에서 어떤 버튼이 눌렸는지 확인하는 데 사용됩니다. |

### QLineEdit 메서드

| 메서드 | 설명 |
|---|---|
| `setAlignment(Qt.AlignmentFlag.AlignRight)` | 텍스트 정렬 방향을 설정합니다. 여기서는 오른쪽 정렬을 적용합니다. |
| `setReadOnly(bool)` | `True`로 설정하면 사용자가 직접 텍스트를 입력할 수 없습니다. |
| `setFixedHeight(int)` | 위젯의 높이를 고정합니다. |
| `setText(str)` | 디스플레이에 표시할 문자열을 설정합니다. |

### QGridLayout 메서드

| 메서드 | 설명 |
|---|---|
| `addWidget(widget, row, col)` | 지정한 행·열 위치에 위젯을 추가합니다. |
| `addWidget(widget, row, col, rowspan, colspan)` | 행·열 위치와 함께 차지할 행/열 범위를 지정하여 위젯을 추가합니다. `0` 버튼이 가로 2칸을 차지할 때 사용됩니다. |

### PyQt6.QtCore

| 상수 | 설명 |
|---|---|
| `Qt.AlignmentFlag.AlignRight` | 텍스트나 콘텐츠를 오른쪽으로 정렬하는 플래그입니다. `QLineEdit.setAlignment()`에 전달하여 숫자가 오른쪽에 표시되도록 합니다. |

### Python 내장 함수

| 함수 | 설명 |
|---|---|
| `eval(expression)` | 문자열로 된 Python 수식을 실행하고 결과를 반환합니다. `'3+4'` → `7`. 잘못된 수식은 예외를 발생시키므로 `try/except`로 감쌉니다. |
| `sys.exit(app.exec())` | `app.exec()`는 PyQt6 이벤트 루프를 시작하고, 창이 닫히면 종료 코드를 반환합니다. `sys.exit()`에 전달하여 프로그램을 정상 종료합니다. |
